\# Squid Game Banner Cycle



An animated looping GIF generator based on the iconic "Red Light, Green Light" sequence from \*Squid Game\*.



\## Preview



!\[Squid Game Cycle](squid\_game\_cycle.gif)



\## Sequence Order



1\. \*\*Green Light Banner\*\* (`Green Light | Luz Verde |`) scrolling on green.

2\. \*\*Young-hee Doll facing tree\*\* (pause).

3\. \*\*Red Light Banner\*\* (`Red Light | Luz Roja |`) scrolling on red.

4\. \*\*Young-hee Doll scanning\*\* (pause).



\## Requirements



\- Python 3.x

\- Pillow (`pip install pillow`)



\## Usage



```bash

python squid\_game\_banner.py
